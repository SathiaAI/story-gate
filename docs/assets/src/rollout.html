TURNING IT ON

Start by warning. Then block one point at a time.

Everything lives in .story-gate/config.json. CI always reads the copy from the pull request's target branch, so a pull request cannot loosen its own rules.

STEP 0

Warn

Everything reports, nothing blocks. Tune for a few weeks.

"mode": "warn"
STEP 1

CI

Pull requests can't merge until the gates pass and a human approves.

"ci"
STEP 2

Before edits

No code edits until READY passes.

"pre_edit"
STEP 3

Mid-story

Off course freezes edits; "done" waits for DONE.

"checkpoint" "stop"
FULL

Enforce

Every point blocks.

"mode": "enforce"
