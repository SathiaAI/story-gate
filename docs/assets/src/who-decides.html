WHO DECIDES

Agents collect. The judge scores. Rules decide. A human accepts.

Nobody grades their own work. The coding model never judges, and nothing an agent writes can approve, waive or merge.

01

Agents

Cheap models fetch the story and specs, plan tests, write the handoff. Small and medium tiers only.

→
02

Evidence

Story, specs, test plan, the diff, real test results, handoff. Locked by fingerprint: any edit means re-check.

→
03

Judge

The judge (Jev by default) scores each check as a probability. Same judge in every client.

→
04

Rules

gate.py turns scores into a verdict: 0.7 and up passes, 0.4 and up is a concern, lower fails.

→
05

Human

A code owner approves the latest commit on GitHub, then merges. Waivers count only after that.
